04 / Engineering principles

The rules behind the work.

01

Read before edit.

Architecture, instructions, local changes and task state come first.

Inspect AGENTS/CLAUDE files, docs, ADRs, git status/diff and the repository's real build/test workflow.
02

Plan before implementation.

Tasks, acceptance criteria and verification are written down before code starts.

The plan stays usable across long sessions, interruptions and handoffs.
03

Smallest safe change.

Fix the root cause without dragging unrelated architecture into the change.

Preserve conventions, dependencies and unrelated local work unless they are part of the actual problem.
04

Verify before done.

Builds, tests, E2E, CI and the final diff decide completion.

A change is complete only when the required checks pass and the final diff is clean.
