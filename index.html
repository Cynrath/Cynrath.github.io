About

Local-first tooling for coding agents that need better repository context.

Cyranth focuses on AI-assisted software development, deterministic repository tooling, secure coding-agent workflows, automation, and maintainable production systems.

The engineering approach is docs-first and task-first: define scope, constraints, acceptance criteria, validation, and rollback before implementation; then produce machine-checkable evidence instead of unverifiable claims.

Featured Project

ACKit — AgentContextKit

Turn any repository into an agent-ready repository. ACKit vNext is an offline-first, deterministic TypeScript/Node.js rebuild designed around a single ackit CLI and the official Model Context Protocol SDK.

  • Instruction graph analysis for Codex, Claude, Gemini, Copilot, nested scopes, overrides, and path rules
  • Agent Skills validation, installation, and synchronization without executing embedded scripts
  • Secret and repository-hygiene scanning with redacted evidence and stable findings
  • Token-budgeted context packs with transparent ranking, manifests, and exclusion reasons
  • Docs-first task workflows, policy-as-code, baselines, incremental scans, and monorepo semantics
  • Terminal, JSON, SARIF 2.1.0, Markdown, HTML, and read-only MCP interfaces

Principles

A workflow built for traceable, safe change.

Docs first

Capture intent, scope, tests, and rollback before implementation details drift.

Task first

Keep changes focused, named, reviewable, and tied to acceptance criteria.

Offline first

Repository analysis should not require uploading source code to a remote AI service.

Deterministic

Prefer explainable, reproducible, machine-readable results and stable contracts.

Production-ready

Validate with lint, format, type checks, build, tests, smoke tests, and CI evidence.

No fake metrics

Keep public claims grounded in repository state and observable validation.
